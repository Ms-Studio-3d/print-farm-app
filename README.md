# MOO3D Business Manager v1.5

نسخة Desktop محلية لإدارة تسعير الطباعة ثلاثية الأبعاد، الأوردرات، الخامات، الطابعات، التقارير، وعروض الأسعار.

## أهم تحديثات v1.5

- محرك تسعير موحد في `js/pricing-core.js` تستخدمه الواجهة والاختبارات.
- دعم تعدد القطع: عدد القطع، سعر القطعة تقريبيًا، وإجمالي السعر للمشروع.
- عروض أسعار: حفظ التسعير كعرض سعر بدون خصم المخزون، ثم تحويله لأوردر عند موافقة العميل.
- نسخ احتياطي تلقائي في `Documents/MOO3D/Backups` عند فتح البرنامج، بعد عمليات مهمة، وعند إغلاقه.
- الاحتفاظ بآخر 10 نسخ احتياطية تلقائية.
- حماية الاستيراد: فحص نوع وإصدار وبنية ملف النسخة الاحتياطية قبل استبدال البيانات.
- اختبار التسعير يتأكد من نفس دالة التسعير المستخدمة داخل التطبيق.

## البناء من GitHub Actions

ارفع الملفات إلى الريبو، ثم شغل Workflow:

`Build Windows Installer`

الـ workflow يستخدم:

- `npm ci`
- `npm test`
- `electron-builder`

## ملاحظات مهمة

- البرنامج يعمل محليًا بالكامل.
- البيانات محفوظة في SQLite داخل بيانات التطبيق.
- النسخ الاحتياطي التلقائي محفوظ خارج بيانات التطبيق داخل Documents.
- عرض السعر لا يخصم خامات. الخصم يحصل عند تحويل العرض إلى أوردر فقط.
