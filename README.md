# MOO3D Business Manager v1.2

نسخة Desktop محلية لإدارة تسعير وأوردرات الطباعة ثلاثية الأبعاد.

## v1.2

- تبسيط شاشة الأوردر: لا يوجد حالة أوردر، لا يوجد مبلغ محصل، لا يوجد حالة تحصيل.
- كل أوردر يعتبر مدفوع بالكامل تلقائيًا لأن نظام العمل يعتمد على الدفع قبل الطباعة.
- فصل الإكسسوارات عن الشحن بدل خانة واحدة.
- الإكسسوارات والشحن يضافان على سعر البيع النهائي فقط بدون فشل وبدون مكسب.
- تبسيط التقارير والأوردرات وإزالة أعمدة التحصيل غير المطلوبة.
- تحسين خفة الحساب أثناء الكتابة عن طريق Debounce بسيط.
- إضافة حفظ قيمة الإكسسوارات في قاعدة البيانات المحلية SQLite.

## البناء

GitHub Actions سيبني ملف Windows Installer تلقائيًا عند الرفع على الفرع main.
