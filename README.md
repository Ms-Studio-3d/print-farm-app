# Print Farm App — MOO3D Upgrade v1.1

تطبيق سطح مكتب مبني بـ Electron لإدارة الطباعة ثلاثية الأبعاد، وحساب التكلفة، ومتابعة المخزون، وتسجيل الأوردرات والمبيعات محليًا على الجهاز.

## أهم التحديثات في v1.1

- تعديل طريقة الحساب لتكون أقرب لمنطق MOO3D الجديد:
  - الإضافات المباشرة مثل الإكسسوارات / الشحن / المصاريف لا يدخل عليها فشل ولا مكسب.
  - الربح = سعر البيع النهائي - تكلفة الإنتاج النهائية - الإضافات المباشرة.
  - التقريب لأعلى أقرب قيمة من الإعدادات.
- إضافة خانات التحصيل:
  - المبلغ المحصل.
  - حالة التحصيل: محصل / جزئي / غير محصل / مرتجع.
  - طريقة الدفع: كاش / Instapay / Vodafone Cash / تحويل بنكي / مختلط / أخرى.
- تحديث قاعدة البيانات SQLite بدون حذف البيانات القديمة.
- تحديث التقارير والفواتير والأوردرات لعرض المحصل والمتبقي وحالة التحصيل.
- تحديث التصدير CSV والـ Backup ليشمل بيانات التحصيل الجديدة.

## المميزات الحالية

- حساب تكلفة الطباعة بناءً على استهلاك الخامة، تكلفة الماكينة، الكهرباء، الشغل اليدوي، التغليف، الفشل، الربح، والخصم.
- إدارة مخزون الخامات وحركات المخزون.
- إدارة الطابعات وتكلفة الساعة.
- تسجيل الأوردرات وخصم الخامات تلقائيًا.
- تعديل وحذف الأوردرات.
- فواتير قابلة للطباعة.
- تقارير وإحصائيات للمبيعات والتحصيل.
- تصدير واستيراد Backup بصيغة JSON.
- بناء نسخة Windows Installer باستخدام GitHub Actions.

## تشغيل المشروع محليًا

```bash
npm install
npm start
```

## بناء نسخة Windows Installer

```bash
npm run dist:win
```

أو استخدم GitHub Actions من تبويب Actions داخل الريبو.
