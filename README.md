# MOO3D PRINT FARM v1.8.1

نسخة Desktop محلية لإدارة تسعير الطباعة ثلاثية الأبعاد، الأوردرات، الخامات، الطابعات، التقارير، وعروض الأسعار.

## إصلاح v1.6.1

- إصلاح زر «تسجيل الأوردر بعد الدفع» ليستخدم دالة التأكيد الصحيحة `window.farmAPI.confirm`.
- تحديث رقم الإصدار في README و package.json.

## أهم تحديثات v1.6.1

- محرك تسعير موحد في `js/pricing-core.js` تستخدمه الواجهة والاختبارات.
- دعم تعدد القطع: عدد القطع، سعر القطعة تقريبيًا، وإجمالي السعر للمشروع.
- عروض أسعار: حفظ التسعير كعرض سعر بدون خصم المخزون، ثم تحويله لأوردر عند موافقة العميل.
- نسخ احتياطي تلقائي في `Documents/MOO3D/Backups` عند فتح البرنامج، بعد عمليات مهمة، وعند إغلاقه.
- الاحتفاظ بآخر 10 نسخ احتياطية تلقائية.
- حماية الاستيراد: فحص نوع وإصدار وبنية ملف النسخة الاحتياطية قبل استبدال البيانات.
- اختبار التسعير يتأكد من نفس دالة التسعير المستخدمة داخل التطبيق.

## البناء من GitHub Actions

ارفع الملفات إلى الريبو، ثم شغل Workflow:

`Build Windows Installer`

الـ workflow يستخدم:

- `corepack enable`
- `corepack prepare pnpm@9.15.9 --activate`
- `pnpm install --frozen-lockfile`
- `pnpm test`
- `pnpm exec electron-builder --win nsis --publish never`

## ملاحظات مهمة

- البرنامج يعمل محليًا بالكامل.
- البيانات محفوظة في SQLite داخل بيانات التطبيق.
- النسخ الاحتياطي التلقائي محفوظ خارج بيانات التطبيق داخل Documents.
- عرض السعر لا يخصم خامات. الخصم يحصل عند تحويل العرض إلى أوردر فقط.


## v1.6
- الشحن يضاف مرة واحدة على الأوردر بالكامل.
- الإكسسوارات والتكاليف المرتبطة بالقطعة تضرب في عدد القطع.
- عدد القطع أصبح رقمًا صحيحًا موجبًا فقط.
- فحص المخزون يتم على إجمالي استهلاك كل القطع قبل التسجيل.
- زر التسجيل أصبح «تسجيل الأوردر بعد الدفع» مع رسالة تأكيد قبل خصم المخزون.
- كل أوردر مسجل يعتبر مدفوعًا بالكامل، وتم تبسيط منطق التحصيل القديم في الواجهة.
- النسخ الاحتياطي بعد العمليات يعمل بعد انتهاء العملية حتى لا ينتظر المستخدم.
- تم إزالة Google Fonts واستخدام خطوط النظام المحلية للعمل بالكامل دون إنترنت.

## v1.7.4 Pricing Logic

- وقت الطباعة يُدخل كإجمالي وقت الأوردر كله، وليس وقت القطعة.
- وزن الخامة يُدخل كإجمالي الجرامات لكل لون/خامة في الأوردر كله.
- التغليف يُدخل مرة واحدة للأوردر كله.
- الإكسسوارات تُدخل للقطعة الواحدة وتُضرب في عدد القطع.
- الشحن يُضاف مرة واحدة للأوردر كله، ويظل الافتراضي 0.
- خصم المخزون يتم على إجمالي الجرامات المدخلة لكل خامة فقط عند تسجيل الأوردر بعد الدفع.

## v1.8.0

- Added business Dashboard with cash drawer, collected amount, purchases total, stock value, asset recovery, and maintenance lamp.
- Added Purchases module. Material purchases can increase existing material stock and appear in stock movements.
- Added Assets module for printer/equipment investment tracking.
- Added cash and maintenance settings: opening cash, previous machine hours, maintenance interval, last maintenance hour, maintenance cost.
- Pricing form now accepts print time as hours + minutes while storing the total internally as hours for backward compatibility.
